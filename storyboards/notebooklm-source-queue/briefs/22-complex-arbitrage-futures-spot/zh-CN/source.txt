# 期货-现货套利：从期现套利到 DeFi-CeFi

*《期货与现货之间的复杂套利链》系列第 2 部分*

在上一部分中，我们讨论了如何使用图算法找到资产交换的复杂路径。但加密货币市场提供了另一个维度的利润——同一资产在不同类型市场之间的价格差异：现货（Spot）和期货（Futures）。

这就是**德尔塔中性（Delta-neutral）策略**的世界，在这种策略中，交易者的利润不依赖于市场的上涨或下跌。

## 1. 核心概念：基差与收敛

本质上，期货-现货套利依赖于**基差（Basis）**——即期货价格 ($F$) 与现货价格 ($S$) 之间的差额：
$$\text{基差} = F - S$$

在期货合约的到期日，期货价格必须等于现货价格（$F = S$）。这被称为**收敛（Convergence）**。

### 1.1 期现套利（Cash-and-Carry）
最经典的策略：
1. **买入现货：** 以 $50,000 买入 1 个 BTC。
2. **卖出期货：** 以 $52,000 卖出 1 个 BTC 的 12 月期货合约。
3. **等待：** 在 12 月份，你交付 BTC。你的利润恰好是 $2,000，无论 BTC 价格如何。

在 Rust 中，我们跨交易所跟踪这些利差，以寻找最高的年化收益率：

```rust
fn calculate_annualized_yield(basis: f64, spot_price: f64, days_to_expiry: f64) -> f64 {
    let yield_pct = basis / spot_price;
    (yield_pct / days_to_expiry) * 365.0 * 100.0
}
```

## 2. 永续合约与资金费率

加密货币中最受欢迎的工具是**永续合约（Perp）**，它永不到期。为了使永续合约价格接近现货价格，交易所使用**资金费率（Funding Rate）**。

- **资金费率为正：** 多头（Long）付给空头（Short）。通常发生在牛市。
- **资金费率为负：** 空头（Short）付给多头（Long）。通常发生在牛市。

### 2.1 资金费率套利
如果资金费率为每 8 小时 0.01%（年化约 11%），你可以：
1. **买入现货** (1 BTC)。
2. **做空永续合约** (1 BTC)。
3. **赚取资金费：** 你每天三次收到持仓价值的 0.01%。

这实际上是无风险的收入，只要你能管理好空头头寸的清算（爆仓）风险。

## 3. DeFi-CeFi 套利：新前沿

随着 dYdX 或 Hyperliquid 等去中心化交易所（DEX）和 Uniswap 等自动做市商（AMM）的兴起，一种新型的链条出现了。

### 3.1 链条逻辑
1. **检测差异：** Binance（中心化交易所）上的 BTC 现货价格为 $50,000，但某个 DEX（去中心化交易所）上的 BTC 永续合约价格为 $50,500，且资金费率很高。
2. **执行：** 在 Binance (CeFi) 买入，在 DEX (DeFi) 做空。
3. **优化：** 如果需要，使用“桥”（Bridge）移动保证金，或者在两侧保持资金平衡。

### 3.2 跨链复杂性
DeFi-CeFi 套利在我们之前的图模型中增加了“气费”（Gas Fees）和“L1/L2 延迟”。你的 Rust 机器人现在需要同时与以太坊/Solana RPC 节点和 Binance API 进行通信。

```rust
async fn monitor_funding(dex_client: &DexClient, cefi_client: &CefiClient) {
    let dex_funding = dex_client.get_funding_rate("BTC-USD").await;
    let cefi_funding = cefi_client.get_funding_rate("BTC-USDT").await;
    
    let spread = dex_funding - cefi_funding;
    if spread > THRESHOLD {
        execute_trade().await;
    }
}
```

## 4. 执行风险：单腿风险与清算

虽然策略是“德尔塔中性”的（没有市场方向风险），但它并非“无风险”。

- **单腿风险（Leg Risk）：** 你买入了现货，但当你尝试做空期货时，价格已经变动，利差消失了。
- **清算风险（Liquidation Risk）：** 如果价格翻倍，你的空头头寸可能会因为保证金不足而被清算，即使你的现货头寸是盈利的。
- **交易所风险：** 如果交易所宕机或被黑客攻击怎么办？

## 5. 结论

期货-现货套利是加密货币的“机构化”一面。它比简单的资产交换需要更多的资金和更好的风险管理，但它的扩展性要好得多。
