# Marketmaker universal end card

One animated end card (outro) for every Marketmaker video: all collections, all
languages. Drawn entirely in code (HyperFrames + GSAP-driven canvas + SVG path
glyphs) on top of the channel-wide "Coral Exchange" kit, with Otto the octopus
market maker holding the four channel signs.

- 1920x1080, 30 fps, 19.0 s, H.264 + AAC 48 kHz stereo
- deterministic: every frame is a pure function of `t` (no `Math.random`, no clocks)
- variable `lang` (`en`, `ru`, `zh-CN`, `zh-TW`): localizes the headline and the
  slot labels, and highlights the matching channel sign (sun-yellow, bobbing, sparkles)
- audio: `assets/bed.m4a`, an instrumental bed cut on downbeats from the channel
  song (vocal-free bars only, -16 LUFS). See `tools/make_bed.sh`.

## Layout

| Zone | Screen px | Content |
| --- | --- | --- |
| header | y 40-240 | logo + `marketmaker.cc`, localized headline banner |
| channels | x 40-1110, y 270-600 | four YouTube signs: English, 简体中文, 繁體中文, Русский |
| YouTube slots | x 1150-1880, y 268-888 | calm dark board, nothing moves there after 2.4 s |
| contacts | y 900-1056 | website, email, X, Discord, Telegram, Telegram (RU), GitHub, Facebook |

### YouTube end-screen elements

The card leaves two dashed slots for the YouTube Studio end-screen elements.
They are visible from 1.7 s and static from 2.4 s, so the end screen can cover
the last 16 s of the video (YouTube allows 5-20 s).

| Element | Slot (px) | Slot (% of frame) |
| --- | --- | --- |
| Video ("Watch next") | x 1190-1830, y 290-650 (640x360) | left 62.0 %, top 26.9 %, width 33.3 % |
| Subscribe | circle centre (1510, 770), r 116 | centre 78.6 %, 71.3 % |

In YouTube Studio: Editor, End screen, set its start to `video length - 16 s`,
add one Video element (Best for viewer or a specific video) and one Subscribe
element, and drag them onto the dashed slots.

## Render

```bash
tools/render_all.sh                 # all four languages -> renders/endcard_<lang>.mp4
LANGS="ru" tools/render_all.sh      # one language
tools/snap.sh "1,3,9" "" '{"lang":"ru"}'   # snapshots of a language
tools/snap.sh "0.3,0.6,0.9,1.3,1.8,2.4,3.5,5,7,9.5,12,15,17.5,18.6" && tools/sheet.sh 7
```

`renders/` is git-ignored. `index.html` is generated by the shared kit build
(`../marketmaker-general/style/kit/tools/build.py .`) from `tools/shell.html`, the
kit and `src/*.js`; it is committed so the card renders even if the kit changes.

Edit text and links only in `src/10_copy.js`. After changing any Chinese string,
run `python3 tools/fetch_cjk.py` (it subsets Noto Sans SC/TC into `assets/fonts/`).

## Append it to a video

The end card is 1920x1080, 30 fps, yuv420p, AAC 48 kHz stereo. Re-encoding the
join is the safe default (it also conforms an episode with another frame rate,
size or sample rate):

```bash
EP=episode.mp4; LANG_CODE=ru
ffmpeg -i "$EP" -i "collections/_endcard/renders/endcard_${LANG_CODE}.mp4" -filter_complex "
[0:v]scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=30,format=yuv420p,setsar=1[v0];
[1:v]fps=30,format=yuv420p,setsar=1[v1];
[0:a]aresample=48000,aformat=sample_fmts=fltp:channel_layouts=stereo[a0];
[1:a]aresample=48000,aformat=sample_fmts=fltp:channel_layouts=stereo[a1];
[v0][a0][v1][a1]concat=n=2:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 192k -ar 48000 -ac 2 -movflags +faststart "${EP%.mp4}_endcard.mp4"
```

If the episode already is H.264 1920x1080 30 fps yuv420p with AAC 48 kHz stereo,
a lossless stream copy also works:

```bash
printf "file '%s'\nfile '%s'\n" "$PWD/$EP" "$PWD/collections/_endcard/renders/endcard_${LANG_CODE}.mp4" > /tmp/endcard_list.txt
ffmpeg -f concat -safe 0 -i /tmp/endcard_list.txt -c copy -movflags +faststart "${EP%.mp4}_endcard.mp4"
```

## Files

- `src/05_logo.js` logo path data (from `marketmaker-cc-landing/public/logo.svg`)
- `src/10_copy.js` headlines, channels, contacts, glyph paths
- `src/20_scene.js` layout, drawing, timeline
- `tools/shell.html` page skeleton (variables, fonts, audio)
- `tools/make_bed.sh` builds `assets/bed.m4a` from the channel song
- `tools/fetch_cjk.py` CJK font subsets; `tools/render_all.sh`, `tools/snap.sh`, `tools/sheet.sh`
- `REVIEW.md` critique and fix rounds
